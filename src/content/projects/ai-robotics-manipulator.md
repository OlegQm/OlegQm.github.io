## Where software meets movement

This project explores the connection between AI and robotics: recognising objects from a camera feed and using those observations to guide a physical manipulator. I developed the project independently, bringing together computer vision, edge hardware, servo control and a mobile interface.

## My contribution

- Implemented camera-based object detection in Python with OpenCV and Hailo tooling on Raspberry Pi.
- Connected target selection and image offsets to servo aiming, with a search routine for a lost target.
- Developed Arduino control for three servomotors.
- Built a C# / Xamarin.Forms mobile interface for selecting targets, requesting camera images and controlling search.
- Worked with YOLO training tools and model conversion, optimisation and compilation for Hailo hardware.

## Engineering focus

The interesting challenge is coordinating perception and movement across different devices. The work spans Python applications, microcontroller control, a mobile interface and the practical constraints of running vision models on edge hardware.

## Physical testing

The project has been tested with a physical robotic arm. The accompanying video shows real-world testing and a search-mode demonstration, bringing the work from software development to physical experimentation.
